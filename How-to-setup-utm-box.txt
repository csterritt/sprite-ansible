Set up tailscale to run at boot time.

This was all up and running, so I was able to skip to the 'Sign in' part.

First, verify that the Tailscale service is installed and recognized by systemd:
    sudo systemctl status tailscaled

If the service is installed, it will show its current status. To enable it at startup, run:
    sudo systemctl enable tailscaled

This command creates the necessary symbolic links so that the Tailscale daemon (`tailscaled`)
launches at boot time. You can start the service immediately without rebooting by executing:
    sudo systemctl start tailscaled

Sign in:
    sudo tailscale up

After enabling the service, confirm it is active and running:
    sudo systemctl is-active tailscaled

Check the 'Machines' section on the tailscale admin page, make sure that the UTM box
has 'tag:devbox', otherwise use its three-dots menu to add it.

try ssh'ing in, if that doesn't work, try:

    sudo tailscale set --ssh=true
    ...try ssh...
    sudo tailscale set --ssh=false
